## Escopo

Inclui os CSVs de contextos/funções e o manifesto de execução de generated/. Não inclui ROMs, ZIPs comerciais, assembly ou dependências. O README é uma cópia de referência; scripts, Makefile e configurações YAML não fazem parte deste pacote documental.

Os SVGs preservam os mapas de memória. As pastas relativas são mantidas. Alguns metadados de execução se referem aos caminhos originais do ambiente, cujos binários não estão neste pacote.
