# Substituições manuais

Reservado a funções C/C++ legíveis que substituam unidades recompiladas verificadas. Cada alteração futura deve citar função, seção/overlay, evidência, motivo e teste de fidelidade. Não editar C gerado nem copiar indiscriminadamente toda a lógica para uma nova engine.

N64Recomp documenta substituição via ordem de ligação de bibliotecas e modo de saída para patches. A configuração concreta será definida somente após existir uma unidade de código validada.
