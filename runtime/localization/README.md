# Localização futura

Reservado a catálogos externos e adaptadores de texto, sem alterar a lógica da simulação. Ainda é necessário rastrear chamadas de texto, encoding, layout e uso de glifos. Não se presume que substituir strings em memória implemente localização completa.

Catálogos próprios podem usar UTF-8 e identificadores estáveis, após identificar pontos de integração. Fontes e imagens derivadas da ROM permanecem em `local/assets/ozumo2/`, fora do Git.
